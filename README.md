# AI Resume Analyzer

🚀 **Live Demo:** 
https://ai-resume-analyzer-3jslsqjf3wca9bkd5ivrx8.streamlit.app/

💻 **GitHub Repository:**
https://github.com/code-4fnan/AI-Resume-Analyzer

An AI-powered Resume Analyzer built using a fine-tuned DistilBERT model.

## Features
- Resume PDF text extraction
- AI-based job category prediction
- Skill extraction
- Job description similarity matching
- Missing skill identification

## Tech Stack
- Python
- Streamlit
- DistilBERT
- Hugging Face Transformers
- PyTorch
- Sentence Transformers
- Scikit-learn

## Run Locally

1. Clone the repository.
2. Install dependencies:
   pip install -r requirements.txt
3. Run the application:
   streamlit run app.py

## Note
The trained model must be available locally for predictions.
